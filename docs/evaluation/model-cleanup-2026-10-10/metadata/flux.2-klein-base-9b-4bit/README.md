# flux.2-klein-base-9b-4bit

This repository contains MLX-Gen saved weights for `black-forest-labs/FLUX.2-klein-base-9B`. The checkpoint is designed for local Apple Silicon inference with [`mlx-gen`](https://github.com/lpalbou/mlx-gen).

It uses the mflux/MLX saved-weight layout and MLX quantization tensors. It is not a Diffusers or Transformers `from_pretrained()` checkpoint.

## Usage

```bash
python -m pip install -U mlx-gen

mlxgen download --model AbstractFramework/flux.2-klein-base-9b-4bit

mlxgen generate \
  --model AbstractFramework/flux.2-klein-base-9b-4bit \
  --prompt "Your prompt here" \
  --steps 20 \
  --seed 42 \
  --output image.png
```
